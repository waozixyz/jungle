# Jungle Academy learning stages

Date: 2026-11-01

This note preserves the agreed long-term direction for Jungle Academy. It is
not a release plan and does not describe features that are available today.

Jungle Academy can remain one umbrella app with independent learning areas:

- **Jungle — early learning:** the gentle watercolor world for pictures, words,
  counting, music and play.
- **Safari — primary learning:** a distinct, more mature visual identity for
  reading, mathematics, science and creative projects. **Math Safari** can be a
  subject area within Safari.
- **Summit — advanced learning:** focused paths in mathematics, AI, computing
  and other subjects that can reach university-level depth, with a style
  suitable for teens and adults.

Learners should progress by readiness within each subject rather than through
rigid age gates. Jungle, Safari and Summit are working names.

Only Jungle is currently available. Safari and Summit are future directions;
no curriculum, interface, dependency or release work is implied by this note.
